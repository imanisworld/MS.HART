# MS.HART — Website Starter

A dependency-free starter tailored to the known shape of Ms. Hart's work: poet, host, activist, creative, and communications professional.

## Current information architecture

- Home / hero
- About
- Practice
  - Poetry
  - Hosting
  - Activism
  - Creative
  - Communications
- Selected Work
  - Writing / publications
  - Hosting / live work
  - Advocacy / community work
  - Creative / communications projects
- Book / Contact

The structure is intentionally broad enough to become a portfolio, booking site, personal platform, or hybrid of all three.

## What is deliberately not invented

We still need her actual:

- preferred name / public-facing styling
- bio
- brand personality
- colors and typography
- portrait and performance imagery
- poetry/publication history
- hosting credits
- advocacy areas she wants public
- creative and communications portfolio
- clients / collaborators she has permission to display
- booking categories
- social links
- contact information
- domain

## Technical starter

- responsive static HTML/CSS/JS
- mobile navigation
- accessible skip link and form labels
- reduced-motion support
- neutral design tokens in `styles.css`
- placeholder 404 page
- contact form intentionally disabled until a real provider is chosen
- no framework or package dependencies

## Run locally

No build step is required.

Open `index.html` directly in a browser, or serve the folder with any local static server.

## Before launch

1. Replace every bracketed placeholder.
2. Decide whether all five practice areas belong at equal prominence.
3. Decide whether activism belongs under Practice, its own Impact page, or only inside selected work.
4. Choose the final visual direction and typography.
5. Add real media under an `assets/` folder.
6. Add actual work entries, links, video/audio, publication links, and event credits.
7. Connect the inquiry form to the selected form/email service.
8. Add favicon, social preview image, canonical URL, and production SEO metadata.
9. Test keyboard navigation, mobile layout, links, embedded media, and form delivery before deployment.

## Design intent

This is no longer a generic small-business template. The information architecture now reflects a multidisciplinary public-facing creative whose site may need to function simultaneously as a portfolio, media/booking destination, writing archive, and professional communications presence. The visual identity remains neutral until she gives us enough information to design it around her rather than around assumptions.
