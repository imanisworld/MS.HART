# MS.HART — Blank Website Starter

A dependency-free starter for building the final MS.HART site once the actual brand, content, services, imagery, and domain are known.

## What is included

- Responsive one-page structure
- Home / hero
- About
- Services
- Work / portfolio
- Contact
- Mobile navigation
- Accessible skip link and form labels
- Reduced-motion support
- Neutral design tokens in `styles.css`
- Placeholder 404 page
- Contact form intentionally disabled until a real provider is chosen

## Run locally

No build step is required.

Open `index.html` directly in a browser, or serve the folder with any local static server.

## Before launch

Replace every bracketed placeholder, especially:

- `[Site Name]`
- page title and meta description
- hero copy
- services
- portfolio / work
- social links
- final images and alt text
- contact details

Then:

1. Choose the final visual direction.
2. Replace the neutral color tokens in `styles.css`.
3. Add real media under an `assets/` folder.
4. Connect the contact form to the selected form/email service.
5. Add a real favicon and social preview image.
6. Add production SEO metadata and canonical URL after the domain is known.
7. Test keyboard navigation, mobile layout, form delivery, and links before deployment.

## Design intent

This starter is intentionally not branded. It gives us a clean technical and content skeleton without locking her into colors, typography, imagery, services, or a business model before she provides that information.
